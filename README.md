# getunworryapp.com

Static website for the Unworry app (landing page, privacy policy, terms). No build step: serve the folder as-is (GitHub Pages, custom domain in `CNAME`).

- Store badges: change `STORES` at the top of `assets/js/site.js` when the app is live.
- Photos: Unsplash (credited on the page and in the footer), self-hosted in `assets/img`.
- Font: Lexend (SIL Open Font License), self-hosted in `assets/fonts`.
